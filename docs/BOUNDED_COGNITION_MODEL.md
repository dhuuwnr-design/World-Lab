# Bounded Cognition Model

WORLD LAB agents must not receive omniscient access to simulation state. Cognition operates on a limited observation stream and persistent internal state.

The initial scaffold separates perception, memory, beliefs, goals/needs/values, action evaluation, and stochastic choice.

Beliefs update gradually from evidence rather than instantly becoming true. Action choice contains bounded stochasticity so identical worlds can produce different trajectories while remaining reproducible under a seed.

This is not a claim that simulated agents are conscious. It is a mechanism boundary that can later support richer planning, language, learning, social reasoning and memory without making an LLM the hidden source of outcomes.

## Reality constraint

Agent mechanisms must eventually be calibrated against empirical human behaviour. Current coefficients are provisional and must not be presented as scientifically established human cognition.
